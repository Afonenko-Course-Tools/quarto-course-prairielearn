# Авторский профиль и нормализованная модель

Версия дополнения — 1.2; минимальная реализация Course Core — 1.1. Схема модели
курса сохраняет `schema: "1.0"`. Дополнение не реализует экспорт в PrairieLearn.

## Область ответственности

Course Core обрабатывает видимость, извлекает упражнения, их условия, заметки
проверки, состав контрольных и канонические идентификаторы. PrairieLearn
добавляет параметры внешней проверки и политику контрольной. Схема CUE
проверяет нормализованный результат, включая неизвестные поля. Проекты
студента, авторские решения и тесты лежат в обычных каталогах, на которые
ссылается атрибут `project`. Генерируемые `question.html`, `info.json`, UUID
и параметры запуска grader не являются обязательными авторскими файлами.

## Политика контрольной

`assessment.prairielearn` — явное подключение политики к конкретной контрольной.
Пустая карта `{}` подключает значения из `prairielearn.assessment-defaults`.
Без подключения глобальные значения не действуют, в том числе на контрольные
с упражнениями других платформ. Видимость обрабатывается ядром раньше
адаптера: удалённая контрольная не оставляет приватную политику.

После объединения требуются все поля:

| Поле | Значение |
|---|---|
| `attempts` | Положительное целое число оцениваемых попыток для каждого задания. |
| `pass.at-least` | Положительное целое число полностью выполненных заданий, не больше длины `.assessment-items`. |
| `assignment` | Одна стратегия назначения: `mode: assessment-id` либо `student-label: <метка>`. |

Локальные поля переопределяют общие; карты объединяются рекурсивно. Исключение —
`assignment`: локальная стратегия целиком заменяет общую. В одной стратегии
нельзя одновременно задавать `mode` и `student-label`. Неизвестные поля и
неподдерживаемые режимы — ошибка. Все члены такой контрольной должны иметь
`target="prairielearn"`; количество определяется ссылками, а не отдельным
счётчиком. Повторы и отсутствующие ссылки проверяет ядро.

При `mode: assessment-id` адаптер получает канонический ID контрольной от
Course Core (`course-assessment-id`) и вычисляет:

```text
student-label = "pl-" + sha1(UTF8(course.id) + byte(0) + UTF8(assessment.id))
```

Хеш SHA-1 здесь — детерминированная метка, не средство безопасности. Переезд QMD
и изменение названия не меняют метку при сохранении ID. Изменение `course.id`
или ID контрольной меняет её. В нормализованную модель попадает только
`assignment.student-label`; исходный `mode` удаляется. Явная метка допустима,
например для общей защиты и пересдачи, и соответствует
`^[a-z][a-z0-9-]*$`. Вычисление метки не назначает её студенту и не ограничивает
доступ на сервере: это отдельная операция развёртывания.

## Условие и критерии проверки

Ядро извлекает `.grading-notes` из упражнения в отдельное необязательное поле
`gradingNotes` модели, а `body` содержит условие без этих заметок. Адаптер
сохраняет эту границу. `.grading-notes` требует явного `course.view` и
автоматически удаляется в представлении `student`. В представлении `full`
заметки остаются в книге и в отдельном поле модели. Само условие задания этот
маркер не скрывает: закрытую контрольную целиком помещают в `.when-full`.
Заметки допускаются только внутри одного упражнения, без вложенных
`.grading-notes`, упражнений и `.assessment-items`.

Будущий компилятор использует `exercise.body` для условия и не вставляет
`gradingNotes`, авторское решение или закрытые тесты в материалы студента.
`project` — путь к исходному проекту, а не разрешение публиковать весь каталог.
Открытая демонстрация с `target="manual"` сохраняется в общей модели и не
попадает в набор вопросов PrairieLearn. Доставка архива стартовых файлов
описывается штатным механизмом Course Core.

## Контракт будущего компилятора

Контрольная включает ровно её `.assessment-items`. Экспортёр использует
`course.id + assessment.id` и `course.id + exercise.id` как устойчивые ключи;
путь файла, номер главы и её название не участвуют в идентичности. Для
закрытой контрольной требуется модель профиля `full`.

`attempts: 3` задаёт три оцениваемые попытки без снижения максимального балла.
`pass.at-least: 2` означает две полностью выполненные задачи. Частичный балл
за незавершённую задачу не считается выполненной задачей. Компилятор обязан
сохранить эту семантику при выборе шкалы оценивания платформы; наличие
частичных баллов само по себе не означает зачёт. Порядок ссылок сохраняется.
Конкретный API доступа, назначение пользователей, контейнер grader, тайм-ауты,
ограничения сети и создание файлов курса относятся к компилятору/развёртыванию.
Эта версия расширения таких действий не выполняет.

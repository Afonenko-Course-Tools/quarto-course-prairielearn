# Кандидат PrairieLearn 9.0.0

Статус unreleased. Исполняемые правила PrairieLearn находятся в существующих
TS owner contracts: declarations, native-business, native-checks, materialization,
grading, submission и публичные schemas. Lua filter остаётся только пустым
техническим именем расширения для Quarto. Старый параллельный author model,
генерируемый словарь и отдельный инструмент проверки схем удалены из продукта,
разработки, тестов и CI.

Один Core native capture передаёт C четыре запрошенные metadata planes.
Прямой вызов validator с DTO выполняет только чистую проверку данных: он не
заполняет business cache и не разрешает доставку или публикацию. Полная C
composition связывает genuine Core operation, prepared generation, exact request,
source witnesses и ordered profiles. Внутри этой операции повторная поставка
seed использует один release proof, но сохраняет currentness перед артефактом;
другая операция, request или отказ сбрасывают cache.

Core передаёт generic project facts, включая скрытые и non-PL declarations.
Поле fact.projectCheck — только selector; document.projectChecks — raw plane
той же capture. Существующий C decodeNativeCheck единолично разрешает PL
policy перед вычислением полного check inventory/hash. Transport selector не
попадает в прежнюю normalized fact/hash область. Проверка plain DTO не делает
его аутентичным producer и не заменяет живые Core source/lifetime guards.

Авторская inspect-grading читает текущую публичную native operation через
inspectPublication. Частичный publication vet не выдумывает topic/submission;
полная delivery требует их и проверяет состав работы/баллы/закрытые ответы.
Старый private collector не является fallback. Main ABI 1 сохраняет явные
extension_id/document_id, режимы permission denial/off/missing-agent, active
snapshot и clearEnv на действительных ordinary child sites. Inert native entry
передаёт запуск публичному Core gate; C auxiliary paths сохраняют frozen env.

Явные seed-targets, recipe A/S0/S1, workspace work, student/full privacy,
нормализованные grading/assignment defaults и существующие hash области
сохранены. Точные обязательные producer→consumer controls и границы ordinary
прогонов фиксируются отдельно в авторском evidence packet.

Окончательный принятый Core 9 pin, paired hosted CI, DIFFERENT OTHER review,
реальные qualified profiles/prior P, полный Java/SP scope и публикация ещё OPEN.
Временный старый CI pin не объявляется Core 9. Никакой ранее опубликованный
тег не изменён; локальная ordinary fixture не доказывает assignment/release.

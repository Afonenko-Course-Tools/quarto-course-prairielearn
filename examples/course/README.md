# Пример курса

Нужны Quarto 1.10.18/1.11.5, CUE 0.17.1 и согласованное ядро курса. CI проверяет Quarto 1.10.18 и 1.11.5.

Из этого каталога:

```sh
quarto add ../../../quarto-course
quarto add ../..
quarto run render.ts student
quarto run render.ts full
```

Пример ожидает локальный checkout `quarto-course` рядом с репозиторием адаптера.
После изменения исходников повторите соответствующий `quarto add`.
При установке Core из GitHub используйте каталог владельца во всех путях обработчиков.
Пример показывает авторскую структуру: публичное упражнение, демонстрацию
`manual`, обычное занятие и закрытую контрольную с правилами попыток и зачёта.
Каталог `projects/clamp` — небольшой образец проекта; контрольные упражнения
показывают связывание метаданных и не являются завершённым учебным материалом.
Java не запускается во время рендера. Авторские файлы остаются в Git;
установленные расширения и результаты сборки исключены.

`render.ts` вызывает обычный `quarto render --profile student|full` в этом
каталоге и проверяет код завершения процесса. Исходники и постоянные кеши Quarto
остаются в этом каталоге. Результаты профилей находятся в `_book/student` и
`_book/full`, текущая полная модель — `_generated/course-spec/course.json`.
Обычные `quarto render`, `quarto preview` и `quarto publish` используют те же
явно подключённые native hooks и фильтры.

См. [правила разметки](../../docs/authoring.md) и
[границу Java/PrairieLearn](../../README.md#java-проекты-и-граница-экспорта).
Модель и HTML не являются native package PrairieLearn: экспорт файлов курса,
Java grader, загрузка задания, студенческая отправка и оценки пока не реализованы
этим адаптером. Профиль full показывает преподавательские материалы, но не
включает такую платформенную интеграцию.

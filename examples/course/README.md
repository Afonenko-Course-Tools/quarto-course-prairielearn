# Пример курса

Нужны актуальные Quarto, CUE и ядро Course Core. CI проверяет каналы Quarto `release` и `pre-release`.

```sh
quarto add AfonenkoA/programming-course-core-specification
quarto add ../..
quarto render --profile student
quarto render --profile full
```

Вместо адреса GitHub можно указать локальный путь к репозиторию ядра.
Пример показывает авторскую структуру: публичное упражнение, демонстрацию
`manual`, обычное занятие и закрытую контрольную с правилами попыток и зачёта.
Каталог `projects/clamp` — небольшой образец проекта; контрольные упражнения
показывают связывание метаданных и не являются завершённым учебным материалом.
Java не запускается во время рендера. Авторские файлы остаются в Git;
установленные расширения и результаты сборки исключены.
